六、widows/orphans 孤行寡行控制

以下段落设置了 widows: 3; orphans: 3，确保分页时页面底部至少保留 3 行，页面顶部至少保留 3 行。 这样可以避免孤行（页面顶部只有一行）和寡行（页面底部只有一行）的排版问题。 这是专业排版中的重要细节，能够显著提升文档的可读性和美观度。 在实际应用中，widows 和 orphans 的值通常设置为 2 或 3，具体取决于文档的排版要求和审美标准。 对于中文文档，由于字符密度较高，通常需要更多的行来保证视觉连贯性。 因此，中文文档的 widows 和 orphans 值建议设置为 3 或 4。 这样可以确保分页处的文本段落保持良好的阅读体验，不会因为分页而造成理解上的断裂。 同时，合理的 widows/orphans 设置也能够减少页面底部的空白，提高页面空间的利用率。 在报纸、杂志等连续排版场景中，这一设置尤为重要。 现代排版软件和专业出版系统都支持这一功能，但在网页排版中，由于浏览器的支持程度不一，往往被忽视。 PaperSharp 引擎完整实现了 CSS Paged Media 规范中的 widows 和 orphans 控制，为高质量的 PDF 输出提供了保障。

七、中文数字页码演示

本报告的页脚使用了中文数字页码格式：counter(page, cjk-ideographic)。 例如：第一页显示为"第一页"，第二页显示为"第二页"，第十页显示为"第十页"， 第十一页显示为"第十一页"，第二十页显示为"第二十页"。

此外，还支持传统中文数字（大写）格式：counter(page, trad-chinese-informal)。 例如：第一页显示为"壹页"，第二页显示为"贰页"，第十页显示为"拾页"。 这种格式常用于财务票据、合同等正式文档，以防止数字被篡改。

M1 里程碑验收要点：
  • 表格 rowspan：跨行合并单元格正确渲染
  • 表格跨页续表：50 行大表格跨页时列宽一致、thead 重复
  • table-caption：表格标题正确定位在表格上方
  • break-inside:avoid：卡片不被分页打断
  • break-before/after:page：强制分页生效
  • widows/orphans：段落分页时无孤行寡行
  • 中文数字页码：页脚显示"第 X 页 / 共 X 页"格式
